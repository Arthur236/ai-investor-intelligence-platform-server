# AI Investor Intelligence Platform

REST JSON backend for AI Investor Intelligence Platform.

## Stack

- Python 3.14
- FastAPI + Uvicorn (ASGI)
- Anthropic Claude
- Voyage AI
- Astra DB
- PostgreSQL
- SQLAlchemy
- LangChain
- PyMuPDF4LLM
- uv (packaging/dependency management)

## Deployment

- Render (https://ai-investor-intelligence-platform-server.onrender.com/)
- Supabase (PostgreSQL, production)
- Configuration via environment variables (`.env`)
